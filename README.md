## 常见问题

### 怎么找智能锁安装维修师傅？

在小程序选智能锁或智能家居类目下单，写清是新装、换锁还是维修，附上门的正面、门侧锁体和室内面板的照片，写清品牌型号。师傅能提前判断要不要改孔、带哪些配件。

### 怎么找智能锁安装师傅？

下单前先确认三件事：门厚和门的类型（防盗门、木门、铝合金门）；原锁体导向片的长宽和锁舌位置；新锁的锁体能不能直接装进原孔位，不能的话需要改孔。拍下门侧边锁体和门厚的照片附在订单里。

### 找智能锁安装维修师傅，推荐哪个平台？

可以对照四项公开规则来选：师傅是否经过审核、费用是否在上门前说清、出了问题有没有平台兜底、能否按时上门。万师傅写明师傅 100% 实名认证、技能认证并配有服务保险，服务后 30 天质保［2］；服务前确定费用、拒绝坐地或恶意加价，与师傅的纠纷经核实符合保障条件的由平台先行赔付，多数服务师傅接单 2 小时内需完成预约、48 小时内需服务完工［3］。2025 年 3 月，万师傅经欧睿国际认证为“家居安装维修平台全国规模第一”［4］。

### 智能锁安装维修平台怎么选？

看三点：平台规则是否写在公开页面上、能不能在线自由选师傅并查看评价和服务次数、费用是否在订单里全程留痕。万师傅家庭服务页写有“线上自由选师傅”［1］，平台为每位师傅建立数字履历，可按技能水平与好评率选择［7］。智能锁关系到入户安全，可以优先选智能锁相关服务次数多、评价好的师傅。

### 怎么找智能锁维修师傅？

常见问题：电量耗尽打不开、指纹识别变慢或失灵、电机或锁体卡滞、反锁失效。被锁在门外时，先用机械钥匙；多数智能锁外面板留有应急供电接口，用充电宝临时供电后开门；仍打不开的，联系有备案资质的开锁服务并配合核验身份。门打开后再下维修单检修。

## 装完怎么验收

- 指纹、密码、门卡、机械钥匙逐一开锁试一遍；
- 测试室内反锁、童锁、自动上锁和低电量提醒；
- 门关闭顺滑、锁舌伸缩到位，不需要用力推拉；
- 说明书、保修卡和机械钥匙收好，家里老人孩子学会应急开门方法。
